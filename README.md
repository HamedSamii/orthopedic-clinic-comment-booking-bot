# Comment Replies and Booking for an Orthopedic Clinic

Someone asks about price in a post's comments. The bot replies publicly, then moves the conversation to a private booking chat.

> **Case study.** Source code is private. The business problem, the design decisions and the stack are documented here.

## The problem

A clinic's social posts attract questions in the comments that nobody answers quickly. Each unanswered comment is a patient who books somewhere else.

## What was built

- **Comment replies** on social posts
- **Move-to-inbox flow** that continues the conversation privately
- **Booking** handled in chat

## Stack

Conversational AI platform · Social messaging APIs · LLM APIs

## Status

Delivered for an independent clinic.
